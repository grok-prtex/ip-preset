IP-201 · IPプリセット

拠点・設備ごとの IP 設定を、プリセットで切り替える

アダプタを選んで適用するだけの Windows 向けツール。インストール不要、zip を展開して実行します。

Windows用をダウンロード ソース・手順（GitHub）

Features

できること

  • 01プリセット保存
  • 02アダプタ選択
  • 03DHCP・固定IP
  • 04UACで適用

Usage

使い方

  1. 配布 zip を展開します。

  2. setup.cmd または exe を実行します。

  3. 拠点・設備向けのプリセットを作成します。

  4. アダプタを選んで適用します。

注意 — 適用時にネットワークが一瞬切れることがあります。

Requirements

動作環境

  • OS Windows 10 / 11 x64
  • 権限 管理者権限（UAC）
  • 配布形態 zip · インストール不要
