拠点の IP を、
プリセットで切り替える

設備調整や別拠点に行くたびに、アダプタの固定 IP や DHCP を手で直していませんか。 IPプリセットは、よく使う設定に名前をつけておいて、選んだアダプタへ一発で適用する Windows 用ツールです。

Windows 用をダウンロード ソースを見る

約 60MB の zip · インストール不要 · Windows 10 / 11 x64

こんなときに

  • 工場の設備網に合わせて、ノート PC の有線を固定 IP にしたい
  • 拠点ごとにゲートウェイや DNS が違う
  • DHCP に戻すのも、また手作業が面倒

できること

  • プリセット 名前付きで DHCP / 固定 IP・マスク・ゲートウェイ・DNS を保存します。
  • アダプタ指定 一覧から対象のネットワークアダプタを選んで適用します。
  • その場で確認 いまの IP 設定を見ながら切り替えられます。
  • 持ち運び exe 横の JSON に保存。USB に入れて現場 PC でも使えます。

実画面は WinForms のシンプルな一枚ものです。見た目より操作の短さを優先しています。

使い方

  1. zip を展開する（好きなフォルダで大丈夫です）
  2. IpPreset.exe を実行する（初回は UAC で管理者承認）
  3. プリセットを追加する。または同梱の例を編集する
  4. アダプタを選んで「適用」

デスクトップに置きたいときは setup.cmd でショートカットを作れます。

注意

  • 適用のあいだ、そのアダプタの通信が短く切れます
  • 会社 PC のポリシーで管理者権限が取れない場合は使えません
  • VPN や Wi‑Fi プロファイル自体は扱いません（アダプタの IPv4 設定のみ）

よくある質問

インストールは必要ですか？
不要です。zip を展開して実行するだけです。ランタイム同梱の単一 exe です。
設定はどこに保存されますか？
実行ファイルと同じフォルダの presets.json です。フォルダごとコピーすれば設定も一緒に移せます。
無料ですか？
はい。ソースは GitHub で公開しています。
