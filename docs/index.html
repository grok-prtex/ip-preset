IPプリセット

拠点・設備ごとに IP 設定を切り替える Windows ツールです。zip を展開して使います。

Windows用 zip をダウンロード GitHub

使い方

  1. 配布 zip を展開します。
  2. IpPreset.exe または setup.cmd を実行します。
  3. プリセットを作成または選びます。
  4. アダプタを選んで適用します。

適用時に、ネットワークが一瞬切れることがあります。

動作環境

  • OS Windows 10 / 11 x64
  • 権限 管理者権限
