# IPプリセット (IpPreset)

工場・現場のPCで、ネットワークアダプター（NIC）のIPアドレス設定を「名前付きプリセット」として登録し、
ワンクリックで切り替えるための、Windows専用の小さなツールです。

現場によってIPアドレス体系が異なる装置・ネットワークに接続する機会が多い方（設備担当・保守担当など）を想定しています。

- **対応OS:** Windows 10 / 11（PowerShell 5.1 同梱環境）
- **配布形式（推奨）:** PowerShell GUI + `.cmd` ランチャー（インストーラ不要・**SmartScreen の青い警告を回避**）
- **画面:** WinForms（PowerShell）。適用ボタンはアクセントオレンジ `#FF6B2C`
- **リポジトリ内:** 従来の C# / .NET 単一 exe プロジェクトも残していますが、**出荷の主成果物は `ps/` です**

> 開発・ビルドに関する情報は [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) をご覧ください。  
> coworker（同僚）への配布方法は [`DISTRIBUTE.md`](DISTRIBUTE.md) をご覧ください。

---

## 1. できること（機能概要）

- パソコンに接続されているネットワークアダプターの一覧表示・選択
- 選択したアダプターの現在のIP設定（DHCP/静的、IPアドレス、サブネットマスク、ゲートウェイ、DNS）を表示
- 「プリセット」（名前・モード・IPアドレスなどをまとめた設定）を登録・編集・削除
- 選択したプリセットを、選択したアダプターに1クリックで適用
  - DHCP（自動取得）プリセットも、静的IPプリセットも両方作成できます
- 適用前に必ず確認ダイアログを表示し、誤操作を防止
- 操作結果・エラーは画面下部の「ログ」欄に日本語で表示

### 非対応（このツールでは扱いません）

- Wi-Fiのプロファイル管理、VPN設定
- IPv6の詳細設定（IPv4のみを対象としています）
- macOS / Linux
- タスクトレイ常駐（将来的な検討事項です）

## 2. 起動と権限（UAC）

**起動時に管理者権限は不要です。** `IpPreset.cmd` をダブルクリックするだけで GUI が開きます。

NICのIP設定変更は Windows の仕組み上、管理者権限が必要です。そのため **「適用」を押したときだけ** UAC（ユーザーアカウント制御）の確認が出ます。「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら「はい」を選択してください。

### SmartScreen（青い警告）について

署名のない `.exe` を配布すると SmartScreen の「WindowsによってPCが保護されました」が出ることがあります。  
本ツールの推奨配布は **PowerShell スクリプト** のため、その青い画面を避けられます。  
コード署名証明書の購入は不要です。

スクリプトがブロックされる場合は同梱の `setup.cmd` を実行するか、`IpPreset.ps1` のプロパティで「許可する」にチェックしてください。`IpPreset.cmd` は `ExecutionPolicy Bypass` と `Unblock-File` を行います。

## 3. 使い方

### 3.1 起動する

1. [Releases](https://github.com/grok-prtex/ip-preset/releases) から `IpPreset-win.zip` を入手して展開します
2. （推奨）`setup.cmd` をダブルクリック → ブロック解除 + デスクトップショートカット
3. `IpPreset.cmd`（またはショートカット）をダブルクリックします

初回起動時、スクリプトと同じフォルダに `presets.json` が無い場合は、サンプルプリセットが自動作成されます。

リポジトリから直接試す場合:

```bat
cd ps
IpPreset.cmd
```

### 3.2 ネットワークアダプターを選ぶ

画面上部の「ネットワークアダプター」から、設定を変更したいNICを選択します。  
選択すると、その下の「現在の状態」に現在のIP設定が表示されます。  
一覧を最新の状態にしたいときは「更新」ボタンを押してください。

### 3.3 プリセットを作成する

1. 「プリセット」欄の「追加」ボタンを押します。
2. 以下の項目を入力します。
   - **プリセット名**: わかりやすい名前（例:「A工場 ライン1」）
   - **モード**: 「DHCP（自動取得）」または「静的（手動設定）」
   - （静的の場合のみ）
     - **IPv4アドレス**: 例 `192.168.1.50`
     - **サブネット**: プレフィックス長（例 `24`）またはサブネットマスク（例 `255.255.255.0`）
     - **ゲートウェイ**: 任意
     - **DNSサーバー**: 任意。カンマ区切り（例 `8.8.8.8, 1.1.1.1`）
     - **メモ**: 任意
3. 「OK」を押すと保存されます。

登録したプリセットは、スクリプトと同じフォルダの `presets.json` に保存されます  
（USBメモリなどで持ち運ぶ場合は、`ps` フォルダ一式と `presets.json` を一緒にコピーしてください）。

### 3.4 プリセットを編集・削除する

一覧からプリセットを選び、「編集」または「削除」ボタンを押します。  
編集はダブルクリックでも開けます。削除の際は確認ダイアログが表示されます。

### 3.5 プリセットを適用する

1. 「ネットワークアダプター」で対象のNICを選択します。
2. 「プリセット」一覧から適用したい設定を選択します。
3. 右側の「適用」ボタンを押します。
4. 確認ダイアログで内容を確認して「はい」を押します。
   - **適用中は一時的にネットワーク接続が切断される場合があります。**
5. 必要なら UAC で承認します。ログ欄に結果が表示されます。

## 4. presets.json について

- 保存場所: **スクリプト（IpPreset.ps1）と同じフォルダ**
- 文字コード: UTF-8
- サンプル: [`ps/presets.example.json`](ps/presets.example.json)（リポジトルートの `presets.example.json` も同内容）
- C# 版と同じスキーマ（camelCase）です

### 項目一覧

| 項目 | 必須 | 説明 |
|---|---|---|
| `name` | ○ | プリセット名 |
| `mode` | ○ | `"dhcp"` または `"static"` |
| `ipv4` | static時のみ | IPv4アドレス |
| `prefixLength` | static時（`subnetMask`と排他） | プレフィックス長（0〜32） |
| `subnetMask` | static時（`prefixLength`と排他） | サブネットマスク |
| `gateway` | 任意 | デフォルトゲートウェイ |
| `dns` | 任意 | DNSサーバーの配列 |
| `note` | 任意 | メモ |

## 5. 安全に関する注意事項

- 適用操作は必ず確認ダイアログを経由します。
- 適用中はネットワークが一時的に切断されることがあります。リモート接続中の操作は特に注意してください。
- パスワードや証明書などの秘密情報は保存しません。`presets.json` にはIPアドレス関連の設定のみです。
- 会社・現場のネットワークポリシーに従い、許可された範囲でご利用ください。

## 6. 手動テストチェックリスト（Windows）

- [ ] `IpPreset.cmd` をダブルクリックすると GUI が開く（起動時 UAC なし）
- [ ] ネットワークアダプターの一覧が表示される
- [ ] アダプターを選択すると、現在のIP設定が表示される
- [ ] 初回起動時、`presets.json` が同じフォルダに自動生成される
- [ ] 「追加」「編集」「削除」が動作する
- [ ] 「適用」で確認ダイアログ → UAC → 実際に NIC 設定が変わる（`ipconfig /all`）
- [ ] DHCP プリセットで自動取得に戻る
- [ ] 不正な値は保存前にエラーになる
