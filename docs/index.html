IPプリセット

設備調整や別拠点で、アダプタの IP を何度も変えるための小さな Windows アプリです。 プリセットを選んで適用するだけ。インストールは不要です。

Windows 用をダウンロード GitHub

使い方

  1. zip を展開する
  2. IpPreset.exe か setup.cmd を実行する
  3. プリセットを作るか選ぶ
  4. アダプタを選んで適用する

適用のあいだ、ネットワークが短く切れます。

動作環境

Windows 10 / 11（x64） · 管理者権限

Grok Prtex · grok-prtex/ip-preset
