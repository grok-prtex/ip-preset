拠点の IP を、
プリセットで切り替える

設備調整や別拠点に行くたびに、アダプタの固定 IP や DHCP を手で直していませんか。 IPプリセットは、よく使う設定に名前をつけておいて、選んだアダプタへ一発で適用する Windows 用ツールです。

Windows 用をダウンロード ソースを見る

軽量 zip（PowerShell）· インストール不要 · SmartScreen回避 · Windows 10 / 11

こんなときに

  • 工場の設備網に合わせて、ノート PC の有線を固定 IP にしたい
  • 拠点ごとにゲートウェイや DNS が違う
  • DHCP に戻すのも、また手作業が面倒

できること

  • プリセット 名前付きで DHCP / 固定 IP・マスク・ゲートウェイ・DNS を保存します。
  • アダプタ指定 一覧から対象のネットワークアダプタを選んで適用します。
  • その場で確認 いまの IP 設定を見ながら切り替えられます。
  • 持ち運び スクリプト横の JSON に保存。USB に入れて現場 PC でも使えます。

実画面は PowerShell WinForms のシンプルな一枚ものです。見た目より操作の短さを優先しています。

使い方

  1. zip を展開する（好きなフォルダで大丈夫です）
  2. （推奨）setup.cmd でブロック解除とショートカット作成
  3. IpPreset.cmd を実行する（起動時 UAC なし）
  4. プリセットを追加し、アダプタを選んで「適用」（適用時のみ UAC）

ダウンロードでスクリプトがブロックされたときも setup.cmd で解除できます。

注意

  • 適用のあいだ、そのアダプタの通信が短く切れます
  • 会社 PC のポリシーで管理者権限が取れない場合は使えません
  • VPN や Wi‑Fi プロファイル自体は扱いません（アダプタの IPv4 設定のみ）

よくある質問

インストールは必要ですか？
不要です。zip を展開して IpPreset.cmd を実行するだけです（Windows 標準の PowerShell）。
設定はどこに保存されますか？
スクリプトと同じフォルダの presets.json です。フォルダごとコピーすれば設定も一緒に移せます。
無料ですか？
はい。ソースは GitHub で公開しています。
