# IPプリセット (IpPreset)

工場・現場のPCで、ネットワークアダプター（NIC）のIPアドレス設定を「名前付きプリセット」として登録し、
ワンクリックで切り替えるための、Windows専用の小さなツールです。

現場によってIPアドレス体系が異なる装置・ネットワークに接続する機会が多い方（設備担当・保守担当など）を想定しています。

- **対応OS:** Windows 10 / 11 (x64) のみ
- **配布形式:** インストーラ不要。exeファイル1つだけで動作します（自己完結・シングルファイル）
- **画面:** シンプルなWinFormsアプリ（アクセントカラーのみジェイド色 `#0E9E6B` を使用）

> 開発・ビルドに関する情報は [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) をご覧ください。
> coworker（同僚）への配布方法は [`DISTRIBUTE.md`](DISTRIBUTE.md) をご覧ください。

---

## 1. できること（機能概要）

- パソコンに接続されているネットワークアダプターの一覧表示・選択
- 選択したアダプターの現在のIP設定（DHCP/静的、IPアドレス、サブネットマスク、ゲートウェイ、DNS）を表示
- 「プリセット」（名前・モード・IPアドレスなどをまとめた設定）を登録・編集・削除
- 選択したプリセットを、選択したアダプターに1クリックで適用
  - DHCP（自動取得）プリセットも、静的IPプリセットも両方作成できます
- 適用前に必ず確認ダイアログを表示し、誤操作を防止
- 操作結果・エラーは画面下部の「ログ」欄に日本語で表示

### 非対応（このツールでは扱いません）

- Wi-Fiのプロファイル管理、VPN設定
- IPv6の詳細設定（IPv4のみを対象としています）
- macOS / Linux
- タスクトレイ常駐（将来的な検討事項です）

---

## 2. 起動時に管理者権限（UAC）が必要です

NICのIP設定変更はWindowsの仕組み上、管理者権限がないと行えません。
そのため **IpPreset.exe は起動時に必ずUAC（ユーザーアカウント制御）の確認画面を表示し、
管理者として実行されます**。「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら
「はい」を選択してください。

---

## 3. 使い方

### 3.1 起動する

`IpPreset.exe` をダブルクリックします。UACの確認が出たら「はい」を選択してください。

初回起動時、実行ファイルと同じフォルダに `presets.json` が無い場合は、
サンプルプリセット（DHCP用・静的IP用それぞれ1件）が自動的に作成されます。

### 3.2 ネットワークアダプターを選ぶ

画面上部の「ネットワークアダプター」から、設定を変更したいNICを選択します。
選択すると、その下の「現在の状態」に現在のIP設定が表示されます。
一覧を最新の状態にしたいときは「更新」ボタンを押してください。

### 3.3 プリセットを作成する

1. 「プリセット」欄の「追加」ボタンを押します。
2. 以下の項目を入力します。
   - **プリセット名**: わかりやすい名前（例:「A工場 ライン1」）
   - **モード**: 「DHCP（自動取得）」または「静的（手動設定）」
   - （静的の場合のみ）
     - **IPv4アドレス**: 例 `192.168.1.50`
     - **サブネット**: プレフィックス長（例 `24`）またはサブネットマスク（例 `255.255.255.0`）のどちらでも入力可能です
     - **ゲートウェイ**: 任意。空欄でも構いません
     - **DNSサーバー**: 任意。複数指定する場合はカンマ区切り（例 `8.8.8.8, 1.1.1.1`）
     - **メモ**: 任意の備考
3. 「OK」を押すと保存されます。

登録したプリセットは、実行ファイルと同じフォルダの `presets.json` に保存されます
（USBメモリなどで持ち運びたい場合は、`IpPreset.exe` と `presets.json` を一緒にコピーしてください）。

### 3.4 プリセットを編集・削除する

一覧からプリセットを選び、「編集」または「削除」ボタンを押します。
編集はダブルクリックでも開けます。削除の際は確認ダイアログが表示されます。

### 3.5 プリセットを適用する

1. 「ネットワークアダプター」で対象のNICを選択します。
2. 「プリセット」一覧から適用したい設定を選択します。
3. 右側の「適用」ボタンを押します。
4. 確認ダイアログが表示されるので、内容を確認して「はい」を押します。
   - **適用中は一時的にネットワーク接続が切断される場合があります。** リモートデスクトップ経由で
     操作している場合などは特にご注意ください。
5. 画面下部の「ログ」に結果が表示されます（成功・失敗いずれも日本語で表示されます）。

適用が完了すると「現在の状態」と「ネットワークアダプター」の情報が自動的に更新されます。

## 4. presets.json について

- 保存場所: **実行ファイル（IpPreset.exe）と同じフォルダ**（ポータブル運用・USBメモリでの持ち運びを優先しています）
- 文字コード: UTF-8
- サンプル: [`presets.example.json`](presets.example.json) を参照してください
- 画面のダイアログから編集するのが基本ですが、テキストエディタで直接編集することも可能です
  （その場合はアプリを再起動するか、内容を反映させるために一度アプリを終了・再起動してください）

### 項目一覧

| 項目 | 必須 | 説明 |
|---|---|---|
| `name` | ○ | プリセット名 |
| `mode` | ○ | `"dhcp"` または `"static"` |
| `ipv4` | static時のみ | IPv4アドレス |
| `prefixLength` | static時（`subnetMask`と排他） | プレフィックス長（0〜32） |
| `subnetMask` | static時（`prefixLength`と排他） | サブネットマスク |
| `gateway` | 任意 | デフォルトゲートウェイ |
| `dns` | 任意 | DNSサーバーの配列 |
| `note` | 任意 | メモ |

## 5. 安全に関する注意事項

- 適用操作は必ず確認ダイアログを経由します。誤って別のアダプターやプリセットを選ばないようご注意ください。
- 適用中はネットワークが一時的に切断されることがあります。リモート接続中の操作は特に注意してください。
- このアプリはパスワードや証明書などの秘密情報は一切保存しません。`presets.json` にはIPアドレス関連の設定のみが保存されます。
- 会社・現場のネットワークポリシーに従い、許可された範囲でご利用ください。

## 6. 手動テストチェックリスト

自動テスト（`dotnet test`）に加え、実機（Windows 10/11）での確認を推奨します。

- [ ] `IpPreset.exe` をダブルクリックすると、UACの確認画面が表示される
- [ ] 起動後、ネットワークアダプターの一覧が表示される
- [ ] アダプターを選択すると、現在のIP設定（DHCP/静的、IPアドレス等）が表示される
- [ ] 初回起動時、`presets.json` が実行ファイルと同じフォルダに自動生成される
- [ ] 「追加」でプリセットを新規作成できる（DHCP・静的の両方）
- [ ] 「編集」で既存プリセットの内容を変更できる
- [ ] 「削除」で確認ダイアログが表示され、「はい」を選ぶと削除される
- [ ] 静的プリセットを選んで「適用」すると、確認ダイアログが表示される
- [ ] 確認後、実際にNICのIPアドレス・サブネットマスク・ゲートウェイ・DNSが変更される
      （`ipconfig /all` で確認）
- [ ] DHCPプリセットを適用すると、NICがDHCP（自動取得）に戻る
- [ ] 不正な値（例: 存在しないIP形式）を入力すると、保存前にエラーメッセージが表示される
- [ ] アプリを閉じて再度開いても、登録したプリセットが保持されている
